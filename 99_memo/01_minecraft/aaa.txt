その後、確認：

```bash
cargo --version
```

こんな感じで出ればOKです：

```bash
cargo 1.xx.x
```

毎回 `source` したくない場合は、zsh に恒久設定します。

これを実行：

```bash
echo 'source "$HOME/.cargo/env"' >> ~/.zshrc
```

反映：

```bash
source ~/.zshrc
```

これで今後 `cargo` が常に使えるようになります。
