### 🖥️ MicroHUD

- **A lightweight and customizable HUD script for Minecraft using Minescript and Minescript Plus.**
- Based on the original MicroHUD script by RazrCraft (GitHub: @R4z0rX), the creator of Minescript Plus.
  - Original source: https://discord.com/channels/930220988472389713/1068545062646059128/threads/1414377991395610646  
- By customizing the HUD in various ways, this script also serves as a good way to learn Minescript and Minescript Plus.  
- https://github.com/sam-ple/minescript-memo/blob/sample/03_utility/18_microhud/microhud_v0.1.00_20251104.py

### 📝 ChatLog

- **ChatLog is a simple utility that records all in-game chat messages to a local text file.**
- Each message is saved with a timestamp, making it useful for moderation, debugging, or reviewing gameplay sessions.
- This script runs continuously and listens for chat events using Minescript’s EventQueue.
- https://github.com/sam-ple/minescript-memo/blob/sample/03_utility/11_chatlog/chatlog_v0.0.01_20250922.py

### ⏱️ Timer

- **Timer is a utility script that provides simple countdown and elapsed-time tracking features.**
- It can be used to manage time limits, display remaining time, or trigger events when a timer reaches zero.
- This utility is useful for mini-games, challenges, and time-based gameplay mechanics.

### 🧹 Flatten

- **Flatten is a utility script that flattens terrain by converting blocks within a specified area to a uniform height.**
- It is useful for map preparation, arena creation, or quickly clearing land for building and mini-games.
- This script requires OP permissions, as it modifies large areas of the world.
- https://github.com/sam-ple/minescript-memo/blob/sample/03_utility/00_flatten/flatten_20250616.py
