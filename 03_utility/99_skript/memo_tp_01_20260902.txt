# ============================================================
# SAFE BIOME / STRUCTURE TELEPORT SYSTEM
#
# Minecraft Java Edition + Paper + Skript
#
# Development Specification Prompt
#
# ============================================================


PURPOSE
============================================================

Minecraft内で、BiomeまたはStructureを検索し、
プレイヤーを安全な地点へテレポートするシステムを作成する。

単純に座標へTPするのではなく、

「プレイヤーが埋もれず、安全に立つことができる場所」

を検索してからTPする。


TARGET DIMENSIONS
============================================================

・Overworld
・Nether
・End

将来的には全Dimensionに対応する。


TARGET TYPES
============================================================

1. BIOME TELEPORT

例：

/biometp plains
/biometp desert
/biometp lush_caves
/biometp warped_forest


2. STRUCTURE TELEPORT

例：

/structuretp trial_chambers
/structuretp ancient_city
/structuretp mansion


BiomeとStructureでは検索方法が異なるが、

最終的な

「安全地点を探してTPする処理」

は共通化する。


CORE CONCEPT
============================================================

安全TPでは、

「自然な地面を探す」

ことを目的としない。


最優先するのは、

「プレイヤーが安全に存在できる空間を探す」

ことである。


したがって、

・土
・石
・草ブロック
・砂
・木の葉
・人工建築物
・構造物の床

など、足場の種類は基本的に限定しない。


重要なのは、

安全な足場があり、
プレイヤーの身体がブロックに埋まらないこと。


SAFE LOCATION DEFINITION
============================================================

安全地点は以下の条件を満たす。


座標構造：

Y+2  空間
Y+1  プレイヤー頭部
Y    プレイヤー足元
Y-1  足場


条件：

1. Y-1にプレイヤーが立てる足場が存在する

2. Y位置が空気または通行可能な安全空間

3. Y+1位置が空気または通行可能な安全空間

4. 必要に応じてY+2も確認する

5. 足場が危険ブロックではない

6. TP先が壁や天井内部ではない

7. TP直後に窒息ダメージを受けない


IMPORTANT PRIORITY
============================================================

Biome TPでは、

「一番上の地面」

を探すことを優先しない。


例えばLush Cavesの場合、

地上の森ではなく、

目的BiomeであるLush Caves内部に存在する
安全地点を探す必要がある。


そのため、

X/Z座標だけではなく、
Y座標を含めた3D空間としてBiomeを判定する。


BIOME SEARCH FLOW
============================================================

1. 指定Biomeを検索

2. 対象Biomeの候補座標を取得

3. 候補X/Z周辺を探索

4. Y座標ごとにBiomeを確認

5. 指定Biome内部の安全地点を探索

6. 安全地点を発見

7. プレイヤーをTP


例：

/biometp lush_caves


↓

Biome候補座標取得


↓

X/Z/Yを確認


↓

minecraft:lush_cavesのY範囲を特定


↓

そのBiome内部で安全地点を検索


↓

Safe TP


STRUCTURE SEARCH FLOW
============================================================

StructureはBiomeではないため、
別の検索方式を使用する。


例：

/structuretp trial_chambers


↓

/locate structure minecraft:trial_chambers


↓

Structure周辺座標を取得


↓

中心座標だけに直接TPしない


↓

中心座標の周辺X/Zを探索


↓

安全な立ち位置を検索


↓

Safe TP


Structure内部では、

・壁内部
・天井内部
・装置内部

などにTPする可能性があるため、

必ず安全空間を確認する。


SAFE LOCATION SEARCH
============================================================

安全地点探索は基本的に、

X/Z候補ごとにY方向を探索する。


検索例：

Y = Dimension最大高度
↓
Yを1ずつ下げる
↓
安全地点条件を確認
↓
最初に見つかった安全地点を採用


ただし、

Biome TPの場合は、

目的BiomeであるY座標内のみを対象とする。


例：

lush_caves

Y=100 plains
Y=90  plains
Y=80  lush_caves
Y=70  lush_caves
Y=60  lush_caves
Y=50  dripstone_caves


この場合、

Y=80～60の範囲のみを
安全地点探索対象とする。


SAFE BLOCK CONDITIONS
============================================================

足場として許可：

基本的にプレイヤーが立てるブロック。


例：

stone
dirt
grass_block
sand
deepslate
netherrack
end_stone
leaves
structure blocks


ただし、

明確な危険ブロックは除外する。


DANGEROUS BLOCKS
============================================================

最低限除外：

lava
magma_block
fire
soul_fire
cactus
campfire
soul_campfire
sweet_berry_bush


必要に応じて追加。


NETHER SUPPORT
============================================================

Netherにも対応する。


対象Biome例：

nether_wastes
crimson_forest
warped_forest
soul_sand_valley
basalt_deltas


ネザーでは、

・溶岩
・マグマブロック
・炎
・狭い洞窟
・ネザー天井
・巨大な空洞

が存在する。


そのため、

「最高地点を探す」

方式ではなく、

指定Biome内部のY範囲を探索し、
安全な3D空間を探す。


END SUPPORT
============================================================

Endにも対応可能。


ただし、

虚空への落下を防止するため、

足場が存在することを必須とする。


必要に応じて、

TP地点周辺にも足場が存在するか確認する。


例：

中心地点
+X
-X
+Z
-Z


最低限、

複数方向に安全な足場が存在することを確認する。


FALL DAMAGE SAFETY
============================================================

将来的な安全強化として、

TP地点の周囲や下方向を確認する。


例：

木の葉の上にTPする場合は許可する。


ただし、

極端に高い位置で、
周囲に安全な移動場所がない場合は
別地点を探索することも検討する。


木の葉は基本的に足場として許可。


IMPORTANT:
「自然な地面かどうか」より
「プレイヤーが安全に存在できるか」を優先する。


COMMON SAFE TP FUNCTION
============================================================

最終的には以下のような共通Functionを作る。


function find_safe_location(
    world,
    center-x,
    center-z,
    search-radius,
    target-biome
) :: location


Structureの場合は、

target-biomeを使用しない。


Biome：

Biome条件
+
安全空間条件


Structure：

Structure周辺範囲
+
安全空間条件


SAFE LOCATION FUNCTION LOGIC
============================================================

候補X/Zを取得

↓

Y方向を探索

↓

足場確認

↓

危険ブロック除外

↓

プレイヤー足元確認

↓

プレイヤー頭上確認

↓

Biome条件確認（Biome TPの場合）

↓

安全地点確定

↓

Locationを返す


TELEPORT EXECUTION
============================================================

安全地点を発見した場合：

1. TP直前に再確認

2. プレイヤーをTP

3. 数tick後に安全確認

4. 必要であれば再TPまたは緊急退避


将来的には、

TP後に窒息ダメージや危険状態を検知する
フェイルセーフも検討する。


MINI TEST DEVELOPMENT ORDER
============================================================

Phase 1
------------------------------------------------------------

単純な安全地点探索テスト。

現在地周辺で、

X/Z固定
Y方向のみ探索。


コマンド：

/safetp test


確認内容：

・足場を検出できるか
・足元が空気か
・頭上が空気か
・安全地点を取得できるか


Phase 2
------------------------------------------------------------

現在地周辺のランダムX/Zで
安全地点を探索。


コマンド：

/safetp random


確認内容：

・木の葉
・洞窟
・山
・地上

などで安全地点を取得できるか。


Phase 3
------------------------------------------------------------

Biome検索テスト。


コマンド：

/biometp <biome>


まずはOverworldの通常Biome。


例：

/biometp desert


Phase 4
------------------------------------------------------------

地下Biome対応。


例：

/biometp lush_caves


Y座標ごとのBiome判定を追加。


Phase 5
------------------------------------------------------------

Nether対応。


例：

/biometp warped_forest


ネザー固有の危険ブロック判定を追加。


Phase 6
------------------------------------------------------------

Structure TP。


例：

/structuretp trial_chambers


/locate structureを利用し、
周辺安全地点を探索。


Phase 7
------------------------------------------------------------

End対応。


Phase 8
------------------------------------------------------------

TP後フェイルセーフ。


窒息、
溶岩、
虚空、
異常状態などを検知。


DESIGN POLICY
============================================================

最初から完成版を作らない。


必ず、

小規模テスト
↓
実際のMinecraftで確認
↓
問題点修正
↓
次の機能追加


という方式で開発する。


最初の目標は、

「現在地周辺で安全な場所を検出してTPできるか」

だけを確認する。


Biome検索やStructure検索は、
安全地点探索ロジックが安定してから追加する。
