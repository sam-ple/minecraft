# **水平方向（Yaw）** と **垂直方向（Pitch）** の角度

## ✅ 水平角度（Yaw）一覧【左右の向き】
| Yawの値 | 向き       | 備考                         |
|---------|------------|------------------------------|
| 0       | 南         | Z軸プラス方向（正面が南）     |
| 90      | 西         | X軸マイナス方向              |
| 180     | 北         | Z軸マイナス方向              |
| -180    | 北（同上） | `180`と同じ                  |
| -90     | 東         | X軸プラス方向                |
| -45     | 南東       | 南と東の中間                 |
| 45      | 南西       | 南と西の中間                 |
| 135     | 北西       | 北と西の中間                 |
| -135    | 北東       | 北と東の中間                 |

## ✅ 垂直角度（Pitch）一覧【上下の向き】
| Pitchの値 | 向き           | 備考                         |
|------------|----------------|------------------------------|
| 0          | 水平（まっすぐ）| 通常の前方を見る向き         |
| -90        | 真上を見る      | 空を真上に見ている            |
| 90         | 真下を見る      | 地面を真下に見ている          |
| -45        | 斜め上を向く    | 見上げている                  |
| 45         | 斜め下を向く    | 見下ろしている                |
