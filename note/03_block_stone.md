## 石系建材の王道とそのバリエーション

### ✅ 基本：`cobblestone`（丸石）

| ブロック名                  | 用途・特徴                                               |
|----------------------------|------------------------------------------------------------|
| `cobblestone`              | 最も基本的な建材。どの時代・ジャンルの建築でも使われる。 |
| `cobblestone_stairs`       | 階段として使用。屋根にも便利。                           |
| `cobblestone_slab`         | 薄型で床・装飾に使える。                                 |
| `cobblestone_wall`         | フェンスや囲いに便利。                                   |
| `mossy_cobblestone`        | 苔むした風合い。古代遺跡や廃墟に最適。                     |
| `mossy_cobblestone_wall`   | 苔ありの壁。風化した建築物の表現に。                     |

## 🧱 石系素材（接頭語で共通パーツあり）

 `*_stairs`, `*_slab`, `*_wall`, `*_bricks`, `*_tiles` など、**接頭語を変えることで多様な建築部材に派生**。

| 素材（接頭語）         | 色味/特徴                           | 建築例                              |
|------------------------|-------------------------------------|-------------------------------------|
| `stone`                | 淡いグレー。プレーンで清潔感あり     | モダン建築、城、街道、床材など     |
| `andesite`             | やや青味のある灰色                   | 工場、下水道、SF建築などに人気     |
| `diorite`              | 白に近い。光沢あり                   | モダン建築、神殿系建築に合う       |
| `granite`              | 赤みがかった石                      | 商業建築、クラシック建築向き       |
| `calcite`              | 真っ白で大理石調                    | 彫刻、神殿、モダン建築の内装など   |
| `tuff`                 | くすんだグレー                      | 地下遺跡、朽ちた建物の表現に       |
| `deepslate`            | 濃い灰色でゴツゴツ感                 | 地下建築、城塞、ダンジョン風建築   |
| `blackstone`           | 真っ黒なネザー由来の石               | ネザー建築、ゴシック建築           |
| `end_stone`            | 薄い黄緑色、エンドの特有ブロック     | 異世界建築、ファンタジー建築       |
| `sandstone`            | 黄土色、砂漠風                      | ピラミッド、神殿、オアシスの建物   |
| `red_sandstone`        | 赤土色、南米っぽい雰囲気             | メサ建築、遺跡、装飾的な壁         |
| `quartz`               | 高級感ある白                       | モダン・未来的・神殿建築           |
| `prismarine`           | 青緑の模様石                        | 水中建築、神殿、海洋風             |
| `nether_brick`         | 赤黒い重厚なブロック                 | ネザー城塞、ダーク建築              |
| `purpur`               | 紫系。エンド系のブロック             | 異世界建築、装飾に使える           |

## 🎨 色味・雰囲気の比較表

| 色系統     | 素材例                        | 雰囲気                   |
|------------|-------------------------------|--------------------------|
| 白系       | `calcite`, `quartz`, `diorite`| 神殿、モダン、清潔感     |
| グレー系   | `stone`, `andesite`, `tuff`   | 都市、現代、工業的       |
| 暗灰/黒系  | `deepslate`, `blackstone`     | 地下建築、要塞、シリアス |
| 赤/茶系    | `granite`, `red_sandstone`    | 遺跡、古代、温かみ       |
| 黄土色     | `sandstone`, `end_stone`      | 砂漠建築、温暖感         |
| 青緑/紫系  | `prismarine`, `purpur`, `warped` | 海中、神秘的、ファンタジー |

## 🧩 建築パターンの例（よく使われる組み合わせ）

- `stone` + `andesite`：モダンや中世街道に定番
- `cobblestone` + `spruce`：村人の家や中世ハウス
- `deepslate` + `blackstone`：ダンジョン・ネザー砦
- `calcite` + `cherry_wood`：ファンタジー風邸宅や神殿
- `sandstone` + `acacia_wood`：砂漠建築・中東風
