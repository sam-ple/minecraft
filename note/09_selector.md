## 🎯 **ターゲットセレクター（Selector）一覧**

### 1. **@p** - 最も近いプレイヤー
- **用途**: コマンド実行者から最も近いプレイヤーをターゲット。
- **例**: `/tp @p 100 64 -100`  
  最も近いプレイヤーを座標 `100, 64, -100` にテレポート。

### 2. **@a** - 全てのプレイヤー
- **用途**: サーバー内のすべてのプレイヤーをターゲット。
- **例**: `/say @a Hello everyone!`  
  サーバー内すべてのプレイヤーにメッセージを送る。

### 3. **@r** - ランダムなプレイヤー
- **用途**: ランダムで1人のプレイヤーをターゲット。
- **例**: `/give @r minecraft:diamond`  
  ランダムに1人のプレイヤーにダイヤモンドを与える。

### 4. **@s** - コマンドを実行したプレイヤー
- **用途**: コマンドを実行した本人（自身）をターゲット。
- **例**: `/tp @s 100 64 -100`  
  コマンドを実行したプレイヤーを座標 `100, 64, -100` にテレポート。

### 5. **@e** - 全てのエンティティ
- **用途**: サーバー内のすべてのエンティティ（プレイヤー含む）をターゲット。
- **例**: `/kill @e[type=minecraft:zombie]`  
  サーバー内のすべてのゾンビを消す。

### 6. **@r[type=<エンティティタイプ>]** - ランダムなエンティティ
- **用途**: ランダムで1つの特定のエンティティをターゲット。
- **例**: `/tp @r[type=minecraft:sheep]`  
  ランダムに1匹の羊をプレイヤーの位置にテレポート。

## 🎯 **ターゲットセレクターの条件（フィルタ）**

ターゲットセレクターに追加の条件を設定することで、特定のプレイヤーやエンティティを絞り込むことができます。

### 1. **[distance=範囲]**
- **例**: `/tp @a[distance=5..10] 100 64 -100`  
  半径5〜10ブロック以内のすべてのプレイヤーを指定した座標にテレポート。

### 2. **[tag=<タグ名>]**
- **例**: `/tp @e[tag=Boss]`  
  `Boss`タグがつけられたすべてのエンティティをターゲット。

### 3. **[name=<名前>]**
- **例**: `/tp @p[name=Steve] 100 64 -100`  
  名前が「Steve」のプレイヤーをターゲット。

### 4. **[type=<エンティティタイプ>]**
- **例**: `/kill @e[type=minecraft:zombie]`  
  ゾンビをすべて消す。

### 5. **[level=<レベル>]**
- **例**: `/tp @a[level=10]`  
  レベルが10のプレイヤーをターゲット。

### 6. **[sort=<ランク指定>]**
- **例**: `/tp @a[sort=nearest]`  
  最も近いプレイヤーをターゲット。

## 🎯 **ターゲットセレクターの使用例**

1. **最も近いプレイヤーにアイテムを与える**
   ```mcfunction
   /give @p minecraft:diamond 64
   ```
   最も近いプレイヤーに64個のダイヤモンドを与える。

2. **指定範囲内のプレイヤーに効果を与える**
   ```mcfunction
   /effect @a[distance=5..10] minecraft:speed 30 1
   ```
   半径5〜10ブロック以内のすべてのプレイヤーにスピード効果を30秒間与える。

3. **タグ付きエンティティにテレポート**
   ```mcfunction
   /tp @e[tag=Boss] 100 64 -100
   ```
   `Boss`タグを持つすべてのエンティティを指定位置にテレポート。

4. **特定の名前のプレイヤーにメッセージを送る**
   ```mcfunction
   /say @p[name=Steve] You are awesome!
   ```
   名前が「Steve」のプレイヤーにメッセージを送る。

5. **ランダムなプレイヤーに音楽ディスクを与える**
   ```mcfunction
   /give @r minecraft:music_disc_pigstep
   ```
   ランダムなプレイヤーに「Pigstep」の音楽ディスクを与える。
