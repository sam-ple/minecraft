## 🏠 建築におすすめの木材（特徴付き）

| 木材系列        | おすすめポイント                                                                 |
|-----------------|----------------------------------------------------------------------------------|
| `oak`           | 最もベーシック。**ナチュラル系建築**に万能で、他の木材との組み合わせもしやすい。         |
| `spruce`        | 暗めの茶色で、**ログハウス**や**中世建築**にぴったり。石やコブルストーンとの相性◎。     |
| `birch`         | 明るい黄白色で清潔感あり。**モダン建築**や**北欧風ハウス**におすすめ。                   |
| `dark_oak`      | 非常に濃い茶色で重厚感あり。**洋館**や**城系建築**に適している。                          |
| `acacia`        | オレンジがかった独特な色味。**近未来風建築**や**砂漠地帯の建物**と相性良し。               |
| `mangrove`      | 深紅っぽい落ち着いた赤。**和風建築**や**装飾建築**に使うと味が出る。                       |
| `cherry`        | ピンク系の明るい色。**ファンタジー建築**や**かわいい系の建物**におすすめ。                 |
| `bamboo`        | 柔らかい黄緑系。**アジアンテイスト建築**や**和風建築**の内装材として人気。                |
| `crimson`       | ネザー系の赤紫色。**ダークファンタジー建築**向け。光源との組み合わせで雰囲気が出る。       |
| `warped`        | ネザー系の青緑色。**未来感のある建物**や**神殿風建築**に◎。                              |
