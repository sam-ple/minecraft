## 🧍 Getting Player Information in Minescript

### 📋 Get All Players

```python
import minescript as m

for p in m.players():
    m.echo(f"{p.name}: pos={p.position} health={p.health}")
```

**Description:**
Retrieves a list of all visible players (within the client’s loaded range) and prints their position and health.

---

### 🧰 Get Players With Equipment (NBT Data)

To access armor, inventory, or other detailed data, use the `nbt=True` option.

```python
import minescript as m

players = m.players(nbt=True)
for p in players:
    m.echo(f"Name: {p.name}")
    m.echo(f"Position: {p.position}")
    m.echo(f"Health: {p.health}")
    if p.nbt:
        m.echo(f"NBT: {p.nbt[:200]}...")  # Truncate for readability
```

**Note:**
`p.nbt` contains the full NBT data as a string — including equipment, inventory contents, and other attributes.

---

### 📍 Get Players Within a Range

```python
import minescript as m

me = m.player()
nearby = m.players(position=me.position, max_distance=30)
for p in nearby:
    m.echo(f"{p.name} is nearby! {p.position}")
```

**Use Case:**
Detect nearby players (for radar HUDs, alerts, etc.).

## Chat

```python
import minescript as m

# Prints a plain-text message to the in-game chat that's
# visible only to you (displayed as white text):
print("Note to self...")

# Same as the previous print(...) statement, except
# that the output to stdout is explicit:
print("Note to self...", file=sys.stdout)

# Same output as the previous print(...) statements,
# but using a Minescript function (behavior can be
# different from above print(...) statements when
# using "Script output redirection"; see below):
m.echo("Note to self...")

# Echo JSON-formatted text (for styled and colored text)
# as a JSON string to the in-game chat only to yourself:
m.echo_json('{"text":"hello!", "color":"green"}')

# Or as a Python dict or list converted to JSON:
m.echo_json({"text":"hello!", "color":"green"})

# Prints a plain-text message to the in-game chat that's
# visible only to you, displayed as yellow text so that
# it's visually distinguishable from text written to stdout:
print("Note to self...", file=sys.stderr)

# Send a chat message that's visible to all players
# in the world:
# m.chat("hi, friends!")

# Log a message to Minecrafts log file
# (in minecraft/logs/latest.log):
m.log("This is a debug message that does not appear in-game.")
```
