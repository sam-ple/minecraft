
## ① Countdown using Gui (minescript_plus) — Local Only

This version does **not** use `/title @a`.
By using **`Gui.set_actionbar()`**, the countdown is displayed **only on the local client (your screen)**.

```python
from time import sleep
from minescript_plus import Gui

print("countdown start")

total_seconds = 10

for t in range(total_seconds, 0, -1):
    minutes = t // 60
    seconds = t % 60
    time_text = f"{minutes:02d}:{seconds:02d}"

    # Display on the local player's actionbar only
    Gui.set_actionbar(time_text)
    sleep(1)

# Clear the actionbar
Gui.set_actionbar("")
print("countdown stop")
```

## ② MicroHUD — Countdown Only Version

This is a **minimal MicroHUD setup** that displays **only a countdown timer**.

```python
from time import sleep
from minescript_plus import Hud

# ============================
# HUD Settings
# ============================
Hud.use_toggle_key(False)  # Disable F12 toggle

# Single-line HUD in the top-left corner
t_countdown = Hud.add_text("", 5, 5)

print("Countdown HUD started")

total_seconds = 10

for t in range(total_seconds, -1, -1):
    minutes = t // 60
    seconds = t % 60
    time_text = f"Countdown: {minutes:02d}:{seconds:02d}"

    Hud.set_text_string(t_countdown, time_text)
    sleep(1)

# Clear the HUD after completion
Hud.set_text_string(t_countdown, "")
print("Countdown HUD finished")
```

---

### Notes

* Both methods are **client-side only**
* **No OP permissions required**
