============================================================
LINERACE GAME SYSTEM
Project Specification / Development Prompt
============================================================

■ 基本概要

Minecraft Java / Paper / Skript で実装するゲーム。

LineRaceは、一直線に伸びた複数のレーンをプレイヤーが進み、
制限時間終了時点で最も遠くまで進んでいたプレイヤーが勝利する
タイムアタック型ゲーム。

ゴール地点は存在しない。

重要：

・最大到達距離を競うゲームではない
・「制限時間終了時点で現在どこにいるか」を競う
・途中で最も遠くまで進んでいても、後退していれば現在位置が記録される
・制限時間0秒になった瞬間の現在位置で順位を決定する


============================================================
■ 現在の基本ルール
============================================================

・コースは一直線
・進行方向はZ+方向
・横方向はX方向
・複数のレーンが存在する
・現在は5レーン
・各レーンは2ブロック幅
・レーンから横方向に逸脱すると死亡
・ゴール判定は存在しない
・制限時間によってゲーム終了

■ レーン逸脱判定
============================================================

ゲーム中は一定間隔で全参加者の位置をチェック。

現在のレーンはZ+方向に伸びているため、
横方向の逸脱判定はX座標だけを見る。

スタートX座標を基準にする。

lateral = 現在X - スタートX

現在の許容範囲：

-1 ～ +1

範囲外になった場合：

プレイヤーをkillする。

死亡したプレイヤーはrespawnする。

spawnpointはスタート地点に設定されている。

そのため、死亡した場合はスタート地点へ戻る。


============================================================
■ 勝敗ルール
============================================================

制限時間終了時点でゲーム終了。

各プレイヤーの「その瞬間の現在位置」を取得する。

距離はスタート地点からZ方向へどれだけ進んだかで判定する。

distance = 現在Z - スタートZ

最も距離が大きいプレイヤーが勝者。

重要：

過去の最大距離は保存しない。

例：

プレイヤーA

100mまで進む
↓
80mまで戻る
↓
制限時間終了

この場合の記録は80m。

100mではない。

つまり、

「制限時間0秒の瞬間に最も前にいる人」

が勝者。

■ 今後追加する予定のゲーム要素
============================================================

ゲーム後半では、プレイヤー同士がコースの端付近で対峙する。

その際、

・弓
・釣り竿
・その他のアイテム
・特殊イベント

などを使用して、相手を後退させたり、
レーンから落としたりする要素を追加予定。

ただし、現在の基本システムにはまだ実装しない。

まずは、

SET
↓
レーン選択
↓
START
↓
カウントダウン
↓
移動
↓
レーン逸脱で死亡
↓
制限時間終了

までを安定させる。

■ 開発方針
============================================================

現在のバージョンでは機能を増やしすぎない。

まず基本システムが正常動作することを確認する。

特に、

・レーン登録
・プレイヤーとレーンの紐付け
・スタート地点保存
・TP
・spawnpoint
・カウントダウン
・ゲーム開始
・横方向逸脱判定
・死亡
・リスポーン
・RESET

を安定させる。

基本動作確認後に、

・制限時間
・現在距離表示
・順位表示
・終了時の勝者判定
・弓
・釣り竿
・イベント
・妨害ギミック

などを段階的に追加する。

既存機能を壊さず、1機能ずつ追加する。
