# Minecraft MineScript テストエリア生成スクリプト仕様プロンプト

## 概要

Minecraft Java Edition + MineScript 用のテスト環境生成スクリプトを作成する。

スクリプトを実行すると、**実行したプレイヤーの現在位置を基準座標として、その周辺に各種Minecraft要素をまとめて配置する**。

目的は、Minecraftの各種ブロック・アイテム・装備・Mob・バイオーム要素・ギミック・コマンドブロックなどを、一度の実行で確認・テストできる環境を作ること。

---

# 1. 基本仕様

* MineScript（Python）で作成する。
* `minescript` を `m` としてimportする。
* `m.execute()` を利用してMinecraftコマンドを実行する。
* スクリプト実行時のプレイヤー位置を取得する。
* 現在位置のX・Y・Zを基準座標として使用する。
* 基準座標は小数を切り捨てて整数座標にする。
* 以降の配置は、基準座標からの相対座標で管理する。
* 相対座標を絶対座標へ変換する関数を用意する。

---

# 2. ワールド・プレイヤー初期設定

スクリプト開始時に以下を実行する。

* モンスターの自然スポーンをOFFにする。
* 難易度をEasyにする。
* 時刻を夜にする。
* 全プレイヤーのインベントリをクリアする。
* 実行プレイヤーを北向き（Yaw 180、Pitch 0）に向ける。

---

# 3. テストエリアの床と空間

現在位置を中心として、約51×51ブロックの範囲を使用する。

### 床

* 基準座標からX方向±25、Z方向±25の範囲。
* 基準Y座標の1ブロック下をgrass_blockにする。

### 空間

* 同じ51×51範囲について、基準Yから上方向に広い空間をairにする。
* 0～9、10～20程度の高さを分けてairにすることで、既存ブロックを除去する。

つまり、実行地点周辺を一度クリアして、テスト用の空間を作る。

# 12. 金ブロック＋怪しげな砂ギミック

基準座標からX=10、Z=-5付近にギミックを作る。

構成：

* 金ブロックを設置。
* 金ブロックの下にRepeating Command Blockを設置。
* プレイヤーが金ブロックの上にいることを検知する。
* 条件を満たした場合、別の場所にSuspicious Sandを出現させる。

つまり、

**金ブロックを踏む → 怪しげな砂が出現する**

という簡単な検証ギミックを作る。

# 15. コンパス＋スニークによる帰還機能

スコアボードを利用して、プレイヤーのSneak状態を検知する。

Objective：

`isSneaking`

Minecraftのsneak_timeを利用する。

プレイヤーが、

* コンパスを手に持っている
* スニークする

という条件を満たした場合、基準地点へTPする。

Repeating Command Blockを使用して常時監視する。

また、スニーク検知後にスコアを0へリセットするため、別のRepeating Command Blockを使用する。

目的は、

**コンパスを持ってしゃがむ → テストエリアの基準地点へ帰還**

という簡易帰還システムを作ること。

# 25. 全体配置イメージ

現在位置を中心に、以下のようなテストエリアを作る。

* Z=-5：Minecraft基本要素展示ライン

* Z=-14：Cat展示
* Z=-18：Frog展示
* 中央付近：TP・帰還・水・溶岩などの機能テスト
* X=5付近：Nether Portal
* X=10付近：金ブロック＋Suspicious Sandギミック

全体として、

**「Minecraftの様々な要素を一箇所に集めた総合テストワールド／テストステージ」**

として機能するようにする。

---

# 26. 実装上の重要事項

* すべての配置位置は現在プレイヤー位置を基準にする。
* 固定されたワールド座標は使用しない。
* `pos(dx, dy, dz)` のような相対座標変換関数を使用する。
* MinecraftコマンドはPythonから `m.execute()` で実行する。
* NBTを使用するMob・チェスト・コマンドブロックについては、Minecraftのバージョンに合わせた正しい構文を使用する。
* 複数の要素をまとめて配置できるため、テスト用ワールドを毎回手作業で構築する必要がないようにする。
* 実行するたびに既存のテストエリアをクリアしてから再構築できる設計を基本とする。
