============================================================
TETSUSEN GAME SYSTEM
Development Handoff / Master Prompt
============================================================

Minecraft Java Edition + Paper + Skript + MineScript で
「鉄千（TETSUSEN）」というミニゲームを開発している。

このプロンプトは、別スレッドでも現在の設計・仕様・既存コード・
開発方針をそのまま引き継ぐためのもの。

今後コードを変更するときは、以下を「現行仕様・基準」とすること。

============================================================
1. GAME CONCEPT
============================================================

鉄千は、5つの焼き場（炉）を使って鉄を集めるタイムアタックゲーム。

各プレイヤーが5つの焼き場のうち1つを選択する。

選択した焼き場にはプレイヤー専用のシェルカーがあり、
そのシェルカー内に入った「鉄インゴット」の数量をゲーム中に監視する。

ゲーム開始後、

    必要個数に到達
        ↓
    そのプレイヤーだけCLEAR
        ↓
    CLEAR時点の時間を記録

する。

1人がCLEARしてもゲーム全体は終了しない。
他のプレイヤーはそのままゲームを続行する。

管理者がSTOPすると、その時点で全員の結果を表示する。

============================================================
6. STATION STRUCTURE
============================================================

各焼き場の中心となるシェルカー：

    minecraft:{color}_shulker_box[facing=north]

シェルカー座標：

    base_x
    base_y
    base_z

シェルカー前面の石ボタン：

    X = base_x
    Y = base_y
    Z = base_z - 1

Minecraft生成時：

    minecraft:stone_button[facing=north]

重要：
Skriptでボタンを判定するときは、

    ボタンの south 側にあるブロック

がシェルカー。

つまり、

    block south of event-block

でシェルカーを取得する。

============================================================
7. STATION SELECTION
============================================================

Skriptでは、

    on right click on stone button

を使う。

処理：

    石ボタンを右クリック
        ↓
    ボタン南側のブロック取得
        ↓
    シェルカーか確認
        ↓
    シェルカーの色判定
        ↓
    プレイヤーと色を紐付け
        ↓
    プレイヤーとシェルカーを紐付け
        ↓
    ボタン削除
        ↓
    通常プレイヤーヘッド設置
        ↓
    空中巨大プレイヤーヘッド設置

現在の変数：

    {tetsusen.station::%player%}
        プレイヤー → 色

    {tetsusen.station.player::%color%}
        色 → プレイヤー

    {tetsusen.shulker::%player%}
        プレイヤー → シェルカー

============================================================
8. PLAYER HEAD
============================================================

現在の実動作仕様では、
通常プレイヤーヘッドは、

    シェルカー + Y1

に配置する。

つまり、

    X = shulker X
    Y = shulker Y + 1
    Z = shulker Z

Skript：

    set {_headLocation} to location of {_shulker}
    add 1 to y-coordinate of {_headLocation}

    set block at {_headLocation} to player head
    set skull owner of block at {_headLocation} to player

重要：
以前MineScriptの旧set2ではY+2だったが、
現在の実動作版SkriptではY+1を使用している。
今後は勝手にY+2へ戻さない。

通常HEAD位置は保存：

    {tetsusen.head::%player%}

    transformation.scale
    set value [6f,6f,1f]

巨大HEAD位置は、

    {tetsusen.bighead.location::%player%}

に保存する。

============================================================
10. BUTTON DELETE / RESET
============================================================

焼き場選択時：

    set event-block to air

でボタンを消す。

RESET時のボタン復元は、
現在実際に動作確認済みの方法を基準とする。

つまり、

    set {_buttonLocation} to location of {_shulker}
    remove 1 from z-coordinate of {_buttonLocation}
    set block at {_buttonLocation} to stone button

を使う。

重要：
過去に、

    execute console command "setblock ... facing=north"

などに変更したときに問題が出た。

そのため今後は、
「動作確認済みの上記のSkript方式」を優先する。

MineScript側の元配置は、

    X = shulker X
    Y = shulker Y
    Z = shulker Z - 1
    facing=north

だが、SkriptのRESETでは
現在動作確認済みの

    set block at {_buttonLocation} to stone button

を使う。

15. COUNTDOWN
============================================================

    3
    ↓
    2
    ↓
    1
    ↓

となる。

を表示した瞬間に、

    {tetsusen.time} = 0

記録タイムはSTART!!から。

x = math.floor(px)
y = math.floor(py)
z = math.floor(pz)

FRONT_Z = z + 5
CHEST_Z = z - 2


def flatten_area():

    m.execute(
        "gamerule send_command_feedback false"
    )

    m.execute("tp @p ~ ~ ~ 0 30")

    x_min = x - 25
    x_max = x + 25

    z_min = z - 25
    z_max = z + 25

    m.execute(
        f"fill "
        f"{x_min} {y-1} {z_min} "
        f"{x_max} {y-1} {z_max} "
        f"minecraft:grass_block"
    )

    m.execute(
        f"fill "
        f"{x-25} {y} {z-25} "
        f"{x+25} {y+9} {z+25} "

def place_all_chests_horizontal():

    offsets_x = [
        -8,
        -5,
        -2,
        1,
        4,
        7
    ]

    contents = [
        ("dried_kelp", 64),
        ("dried_kelp", 64),
        ("diamond_pickaxe", 1),
        ("diamond_pickaxe", 1),
        ("torch", 64),
        ("torch", 64),
    ]

    for offset_x, content in zip(offsets_x, contents):

        cx = x + offset_x
        cy = y
        cz = CHEST_Z

        m.execute(
            f"setblock "
            f"{cx} {cy} {cz} "
            f"minecraft:chest[facing=south,type=right]"
        )

        m.execute(
            f"setblock "
            f"{cx+1} {cy} {cz} "
            f"minecraft:chest[facing=south,type=left]"
        )

        item_id, count = content

        for slot in range(27):

            if item_id == "diamond_pickaxe":

                ench = (
                    '[enchantments='
                    '{"minecraft:efficiency":5,'
                    '"minecraft:fortune":3}]'
                )

                m.execute(
                    f'minecraft:item replace block '
                    f'{cx} {cy} {cz} '
                    f'container.{slot} '
                    f'with minecraft:diamond_pickaxe'
                    f'{ench} 1'
                )

                m.execute(
                    f'minecraft:item replace block '
                    f'{cx+1} {cy} {cz} '
                    f'container.{slot} '
                    f'with minecraft:diamond_pickaxe'
                    f'{ench} 1'
                )

            else:

                m.execute(
                    f'minecraft:item replace block '
                    f'{cx} {cy} {cz} '
                    f'container.{slot} '
                    f'with minecraft:{item_id} {count}'
                )

                m.execute(
                    f'minecraft:item replace block '
                    f'{cx+1} {cy} {cz} '
                    f'container.{slot} '
                    f'with minecraft:{item_id} {count}'
                )

        m.execute(
            f'summon minecraft:item_frame '
            f'{cx} {cy} {cz+1} '
            f'{{Facing:3,Invisible:1b,'
            f'Item:{{id:"minecraft:{item_id}",Count:1b}}}}'
        )
