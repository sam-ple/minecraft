============================================================
TETSUSEN GAME SYSTEM
Project Specification / Development Prompt
============================================================

■ 基本概要

Minecraft Java / Paper / Skript で実装するゲーム。

「鉄千」は、各プレイヤーが自分の焼き場で鉄インゴットを集め、
指定された必要個数を達成するまでの時間を競うゲーム。

プレイヤーごとに焼き場を割り当てる。

現在の焼き場は、

・red
・blue
・green
・yellow
・purple

の5か所。

1人につき1焼き場。

1焼き場につき1人。


============================================================
■ ゲームフロー
============================================================

/tetsusen

↓

GUI

SET
START
STOP
RESET


============================================================
■ SET
============================================================

SETを押すと、前回のゲーム状態をリセットし、
焼き場選択モードにする。

ゲーム中はSET不可。

カウントダウン中もSET不可。

SET時に以下をリセット：

・プレイヤーと焼き場の紐付け
・焼き場情報
・プレイヤーヘッド
・巨大プレイヤーヘッド
・ボタン
・スコア
・クリア情報
・クリアタイム
・必要個数
・ゲーム時間


============================================================
■ 焼き場選択
============================================================

焼き場の石ボタンを右クリックして選択。

ボタンの南側にあるShulker Boxの色を判定する。

対応色：

red
blue
green
yellow
purple

プレイヤーがすでに焼き場を選択している場合は選択不可。

焼き場がすでに他プレイヤーに使用されている場合も選択不可。


============================================================
■ 焼き場選択時の演出
============================================================

選択した焼き場の、

・ボタンを削除
・Shulker Boxの上に通常サイズのプレイヤーヘッドを設置
・プレイヤーの頭を表示
・空中に巨大プレイヤーヘッドを表示

巨大プレイヤーヘッドはItem Displayを使用。

現在の配置：

Y + 10
Z + 2

現在のScale：

X = 6
Y = 6
Z = 1


============================================================
■ START
============================================================

STARTを押す。

SETが完了していない場合は開始不可。

すでにゲーム中の場合は開始不可。

カウントダウン中の場合も開始不可。


============================================================
■ 必要鉄個数
============================================================

START後、必要個数選択GUIを表示。

現在の選択肢：

10
100
200
300
500
1000

選択された値を、

{tetsusen.required}

に保存する。


============================================================
■ カウントダウン
============================================================

必要個数選択後、

3
2
1
START

のカウントダウン。

各カウントでTitleとSoundを使用。

カウントダウン中は、

{tetsusen.countdown} = true

ゲーム開始時に、

{tetsusen.countdown} = false
{tetsusen.running} = true

とする。

カウントダウン中にSTOPされた場合、
ゲーム開始まで進まない。


============================================================
■ ゲーム中
============================================================

ゲーム中は1秒ごとに処理する。

{tetsusen.running} = true

の間、

{tetsusen.time}

を1秒ごとに+1する。


============================================================
■ 鉄の個数計測
============================================================

各プレイヤーのShulker Box内を確認。

Iron Ingotの個数を合計する。

その値を、

iron_count

というScoreboard Objectiveに反映する。

Sidebarにiron_countを表示。


============================================================
■ CLEAR条件
============================================================

現在の鉄数が、

{tetsusen.required}

以上になった場合CLEAR。

CLEARしたプレイヤーについて、

・CLEARフラグ
・CLEAR時間

を保存する。

CLEAR後は以降の鉄数チェックを行わない。


============================================================
■ CLEAR演出
============================================================

CLEAR時：

・CLEAR Title
・プレイヤー名
・クリアタイム
・Sound
・Firework Particle
・Chat通知

を表示。


============================================================
■ STOP
============================================================

STOPを押すとゲームを終了する。

カウントダウン中の場合：

カウントダウンを中止。

ゲーム中でない場合：

「ゲームは開始されていません」と表示。


ゲーム中の場合：

{tetsusen.running} = false

SidebarをOFFにする。


============================================================
■ RESULT
============================================================

STOP時に全プレイヤーの結果を表示。

CLEAR済み：

プレイヤー名
鉄個数
CLEAR
クリアタイム

を表示。

未CLEAR：

プレイヤー名
現在の鉄個数
未達成

を表示。


============================================================
■ RESET
============================================================

RESETを押すとゲームを完全初期化。

以下をリセット：

・running
・setup
・countdown
・プレイヤーと焼き場の紐付け
・焼き場情報
・通常プレイヤーヘッド
・巨大プレイヤーヘッド
・ボタン
・Scoreboard
・必要個数
・ゲーム時間
・CLEAR情報
・CLEARタイム
・最終鉄数


============================================================
■ ワールド運用
============================================================

重要：

同じワールドで鉄千を何度も繰り返す運用ではない。

基本的に、

World A
↓
鉄千
↓
ゲーム終了
↓
World B
↓
別のゲーム

という運用。

そのため、過度な再利用性や複雑なセッション管理は不要。

SET / RESETによって次のワールドで新しいゲームとして開始できればよい。


============================================================
■ 開発方針
============================================================

現在の基本システムを壊さず、
1機能ずつ追加する。

特に重要なのは、

・焼き場選択
・1人1焼き場
・焼き場の重複防止
・プレイヤーヘッド表示
・巨大プレイヤーヘッド表示
・必要個数選択
・カウントダウン
・鉄数カウント
・Scoreboard
・CLEAR判定
・クリアタイム
・STOP
・RESULT
・RESET

を安定させること。

不要な機能を先回りして追加しない。

■ 技術環境
============================================================

Minecraft Java Edition
Paper
Skript

必要に応じてMinecraftのconsole commandを使用する。
